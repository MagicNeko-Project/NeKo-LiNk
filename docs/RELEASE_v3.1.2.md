# NekoLink v3.1.2 更新日志 ฅ^•ﻌ•^ฅ

本次更新是一个重要的架构调整版本，旨在解决 “原生 TCP 模式” 与 “侧车模式 (udp2raw)” 之间的设计冲突，并显著提升了原生 TCP 隧道的稳定性。

## 🚀 新增特性与改进

### 1. 🎭 解耦 Fake-TCP 与 原生 TCP
- **新增模式 `fake-tcp`**：正式将依赖 `udp2raw` 的伪装模式独立。如果您需要极强的抗封锁能力，请显式选择此模式。
- **重构 `tcp` 模式**：原生 TCP 模式（基于 `udp-over-tcp`）现在是完全独立的极简驱动，不再调用 `udp2raw`。这解决了旧版本中两者相互干扰导致的连接中断问题。

### 2. 🔌 原生 TCP 驱动强化 (nekolink-core)
- **修复真实端点识别**：修正了核心层在处理 TCP 流时对解析对端地址的逻辑。现在原生 TCP 连接能正确进行速率限制、重放保护以及 Cookie 校验，完美支持多客户端并发连接。
- **开销优化**：原生 TCP 模式现在拥有专属的 MTU 计算逻辑，不再预留 udp2raw 的开销，理论上传输效率提升了约 1%。

### 3. 📝 文档大合并与瘦身
- 合并了根目录下的 `README_CN.md` 与 `README.md`，现在统一使用包含最新模式说明的中文 README。
- 清理了根目录下冗余的 SOCKS5 指南，所有文档现在统一归档在 `docs/` 目录下。

## 🛠️ 修复与更新
- **版本号同步**：全局版本号正式步入 `3.1.2` 时代。
- **依赖同步**：更新了所有子模块间的相互依赖版本，确保编译链路一致。

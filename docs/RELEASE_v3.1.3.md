# Release v3.1.3 ฅ^•ﻌ•^ฅ

本项目本次更新主要针对 **TCP 传输模式** 进行了深度的架构优化和重构，显著提升了连接的稳定性、响应速度以及多模式下的信令精准度喵！

## 🚀 重大更新

### 1. 原生 TCP (Native TCP) 模式增强
- **异步按需连接**：`nekolink-core` 现在采用完全非阻塞设计。TCP 连接不再在启动时同步建立，而是在有业务数据或握手需求时自动在后台触发喵。
- **自动故障恢复**：链路意外中断后，系统会自动检测并在下一次通信请求时无缝重新连接。
- **信令精简化**：原生 TCP 模式下的信令交换变得更加纯粹，仅保留必要的密钥和 MTU 信息，彻底告别冗余开销。

### 2. Fake-TCP (udp2raw) 模式独立重构
- **深度隔离**：将 `fake-tcp` 模式作为独立的传输选项。此模式现在与原生 TCP 逻辑完全解耦，互不干扰。
- **自动侧车管理**：`nekolink-ctl` 现在能智能识别 `fake-tcp` 模式并自动管理 `udp2raw` 进程的生命周期，实现“零配置”启动。
- **端口动态协商**：信令系统现在支持动态交换 Fake-TCP 的下层物理端口，灵活适配各种复杂的 NAT 环境。

### 3. MTU 探测与校准魔法
- **精准度量**：更新了 MTU 自动探测算法，将 TCP framing 开销精准计入，确保隧道包在各种链路下都能保持最优性能，不分片。

## 🛠 修复与改进
- **清理 Sidecar 术语**：在配置和日志中统一了传输模式的称呼，避免因术语模糊导致的困扰。
- **状态报告优化**：`status` 指令现在能精准显示当前运行的 TCP 模式细节。
- **修复启动假死**：解决了在网络不畅时可能导致的 `nekolink-ctl` 启动挂起问题。
